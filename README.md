# Интернет-магазин «Web-Larёk»

«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме **MVP (Model-View-Presenter)**, которая обеспечивает четкое разделение ответственности:
- **Model (Модель)** — слой данных, отвечает за хранение и бизнес-логику работы с данными.  
- **View (Представление)** — слой отображения, отвечает за вывод данных на экран и перехват действий пользователя.  
- **Presenter (Презентер)** — связующее звено, содержит основную логику приложения, обрабатывает события от View и обновляет Model, а также реагирует на изменения в Model, обновляя View. Код презентера реализован в основном скрипте `main.ts`.

Взаимодействие между слоями осуществляется через брокер событий (событийно-ориентированный подход).

## Базовый код

### Класс `Component<T>`
Базовый абстрактный класс для всех компонентов интерфейса. Является дженериком и принимает тип данных `T`, которые могут быть переданы в метод `render`.
**Поля:**
- `container: HTMLElement` — корневой DOM-элемент, за отображение которого отвечает компонент.
**Методы:**
- `render(data?: Partial<T>): HTMLElement` — принимает данные для отображения, применяет их к DOM-элементу (через сеттеры дочерних классов) и возвращает обновленный элемент.
- `toggleClass()`, `setText()`, `setDisabled()`, `setImage()` — инструментарий для работы с DOM-элементами.

### Класс `Api`
Содержит базовую логику отправки сетевых запросов.
**Поля:**
- `baseUrl: string` — базовый URL для запросов.
- `options: RequestInit` — базовые опции для `fetch` (например, заголовки).
**Методы:**
- `get(uri: string)` — выполняет GET-запрос.
- `post(uri: string, data: object, method: ApiPostMethods = 'POST')` — выполняет запросы с передачей тела (POST, PUT, DELETE).
- `handleResponse(response: Response)` — обрабатывает ответ от сервера.

### Класс `EventEmitter`
Брокер событий, реализующий паттерн «Наблюдатель». Позволяет компонентам подписываться на события и инициировать их.
**Поля:**
- `_events: Map<EventName, Set<Subscriber>>` — коллекция подписчиков на события.
**Методы:**
- `on(event: string, callback: Function)` — подписка на событие.
- `off(event: string, callback: Function)` — отписка от события.
- `emit(event: string, data?: object)` — вызов события с передачей данных.
- `trigger(event: string, context?: object)`- создает функцию-триггер для генерации события.

## Данные и типы данных (Слой Model)

В приложении используются следующие интерфейсы:
- `IProduct` - карточка товара (`id`, `title`, `description`, `image`, `category`, `price`).
- `IBuyer` - данные покупателя (`payment`, `email`, `phone`, `address`).
- `IOrder` - интерфейс заказа для отправки на сервер (наследует `IBuyer`, добавляет `total` и массив `items`).
- `IOrderResult` - ответ сервера после успешной оплаты (`id`, `total`).
- `IProductList` - ответ сервера со списком товаров.
- `TPayment` - тип способа оплаты (`'card' | 'cash'`).

### Класс `ProductsData`
Хранит массив товаров и управляет предпросмотром.
**Поля:**
- `_items: IProduct[]` — массив товаров каталога.
- `_preview: IProduct | null` — товар, выбранный для предпросмотра в модальном окне.
**Методы:**
- `items` (сеттер/геттер) — сохраняет и возвращает каталог товаров.
- `getItem(id: string)` — возвращает товар по ID.
- `preview` (сеттер/геттер) — управляет товаром, выбранным для модального окна.

### Класс `BasketData`
Управляет логикой корзины покупок.
**Поля:**
- `_items: IProduct[]` — массив товаров, добавленных в корзину.
**Методы:**
- `add(product: IProduct)` — добавление товара.
- `remove(id: string)` — удаление товара.
- `clear()` — полная очистка корзины.
- `getTotal()` — подсчет общей суммы заказа.
- `count()` — количество товаров в корзине.
- `contains(id: string)` — проверка наличия товара в корзине.
- `items` (геттер) — возвращает массив товаров в корзине.

### Класс `UserData`
Управляет данными покупателя для оформления заказа.
**Поля:**
- `payment: TPayment | null` — выбранный способ оплаты.
- `email: string` — электронная почта покупателя.
- `phone: string` — телефон покупателя.
- `address: string` — адрес доставки.
**Методы:**
- `setField(field, value)` — устанавливает значение конкретного поля и генерирует событие об изменении.
- `validate()` — проверяет заполненность данных и возвращает объект с ошибками.
- `clear()` — очищает данные пользователя и генерирует событие.
- `getUserData()` — возвращает собранный объект данных покупателя.

## Компоненты представления (Слой View)

Все классы представления наследуются от базового класса `Component<T>`. DOM-элементы, с которыми взаимодействуют классы, ищутся единожды в конструкторе и кэшируются в защищенных полях.

### Класс `Page`
Управляет отображением главной страницы.
**Поля:**
- `_counter: HTMLElement` — счетчик товаров в корзине.
- `_catalog: HTMLElement` — контейнер для карточек товаров.
- `_wrapper: HTMLElement` — обертка страницы (для блокировки скролла).
- `_basket: HTMLElement` — иконка корзины в шапке.
**Методы:**
- Сеттер `counter` — обновляет счетчик.
- Сеттер `catalog` — выводит массив карточек на страницу.
- Сеттер `locked` — блокирует прокрутку страницы при открытии модального окна.

### Класс `Modal`
Управляет модальными окнами.
**Поля:**
- `_closeButton: HTMLButtonElement` — кнопка закрытия окна.
- `_content: HTMLElement` — контейнер для контента внутри модального окна.
**Методы:**
- Сеттер `content` — заменяет содержимое окна переданным HTML-элементом.
- `open()` / `close()` — управляют видимостью окна, вешают слушатели на клик по оверлею и крестику.

### Иерархия карточек товара (Card, CardCatalog, CardPreview, CardBasket)
Универсальные компоненты карточки товара для разных контекстов.

**Абстрактный класс `Card<T>`** (базовый)
**Поля:**
- `_title: HTMLElement` — заголовок карточки.
- `_price: HTMLElement` — цена товара.
**Сеттеры:** `title`, `price`.

**Класс `CardCatalog`** (наследует `Card`) - для главной страницы.
**Поля:**
- `_image: HTMLImageElement` — изображение товара.
- `_category: HTMLElement` — категория товара.
**Сеттеры:** `image`, `category`.

**Класс `CardPreview`** (наследует `CardCatalog`) - для модального окна.
**Поля:**
- `_text: HTMLElement` — описание товара.
- `_button: HTMLButtonElement` — кнопка "В корзину" / "Удалить".
**Сеттеры:** `text`, `buttonText`, `price` (переопределен для блокировки кнопки, если цена null).

**Класс `CardBasket`** (наследует `Card`) - для элемента в корзине.
**Поля:**
- `_button: HTMLButtonElement` — кнопка удаления (иконка корзины).
- `_index: HTMLElement` — порядковый номер в списке.
**Сеттер:** `index`.

### Класс `Basket`
Компонент модального окна корзины.
**Поля:**
- `_list: HTMLElement` — контейнер для списка элементов.
- `_total: HTMLElement` — элемент с итоговой суммой.
- `_button: HTMLButtonElement` — кнопка "Оформить".
**Сеттеры:**
- `items` — заменяет элементы списка и блокирует кнопку при пустой корзине.
- `total` — выводит общую сумму.

### Иерархия форм (Form, OrderForm, ContactsForm)
**Абстрактный класс `Form<T>`**
**Поля:**
- `_submit: HTMLButtonElement` — кнопка отправки формы.
- `_errors: HTMLElement` — блок для вывода ошибок валидации.
**Сеттеры:** `valid`, `errors`.

**Класс `OrderForm`** (наследует `Form`)
**Поля:**
- `_buttons: HTMLButtonElement[]` — коллекция кнопок выбора способа оплаты.
- `_addressInput: HTMLInputElement` — поле ввода адреса доставки.
**Сеттеры:** `payment`, `address`.

**Класс `ContactsForm`** (наследует `Form`)
**Поля:**
- `_emailInput: HTMLInputElement` — поле ввода email.
- `_phoneInput: HTMLInputElement` — поле ввода телефона.
**Сеттеры:** `email`, `phone`.

### Класс `Success`
Окно успешного оформления заказа.
**Поля:**
- `_close: HTMLElement` — кнопка "За новыми покупками".
- `_total: HTMLElement` — блок с текстом о списанной сумме.
**Сеттер:** `total`.

## События в приложении (Presenter)

Логика взаимодействия слоев описана в `main.ts` с помощью подписок на события (`events.on`).

### События изменения данных (Model -> View)
- `items:changed` - загружен каталог товаров, триггерит отрисовку главной страницы.
- `basket:changed` - изменился состав корзины, обновляет счетчик на иконке.
- `formErrors:changed` - результат валидации форм, разблокирует/блокирует кнопки сабмита и выводит текст ошибок.

### События пользовательского интерфейса (View -> Presenter)
- `card:select` - клик по карточке в каталоге. Передает данные товара и открывает модальное окно.
- `basket:open` - клик по иконке корзины. Собирает данные из `BasketData` и рендерит окно корзины.
- `order:open` - клик «Оформить» в корзине. Открывает первую форму оформления (адрес и оплата).
- `order:submit` — успешный сабмит первой формы, переход ко второй форме оформления (контакты).
- `order contacts:change/`- изменение любого поля ввода. Сохраняет данные в `UserData` и запускает валидацию.
- `contacts:submit` - успешный сабмит контактов. Формирует объект `orderData`, делает POST запрос `api.orderProducts()`. При успехе открывает `Success`, очищает корзину и данные покупателя.
- `modal:open` / `modal:close` - блокируют и разблокируют прокрутку страницы (`page.locked`).
